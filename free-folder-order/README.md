# Free Folder Order

在 Obsidian 文件浏览器中直接拖拽，像 Notion 一样自由排序和移动文件夹/文件。

## 安装

本插件未上架社区市场，手动安装：

1. 下载本目录（`free-folder-order/`，为合集仓库的一个子目录）
2. 把整个文件夹放进 `<你的库>/.obsidian/plugins/`
3. 设置 → 第三方插件 → 启用「Free Folder Order」

> 说明：目录里的 `main.js` 即插件本体（带注释的可读构建产物，无独立源码工程），
> 可直接安装使用。`data.json` 是本机排序数据，不随仓库分发。

## 交互（v1.3）

- 行的**任意位置**按住拖动；鼠标在目标行**上半部**＝插到它前面，**下半部**＝插到它后面
- 插入指示是**横跨目标行整行宽度的蓝色粗横线**，出现在行的上方或下方
- **跨层级移动**：把条目拖到某个文件夹行的**中央区域**、**光标保持静止约 0.9 秒**，文件夹自动展开，展开后把条目落到里面任意目标行旁边，即自动移动进该层级并排到该位置
- **空文件夹**：同样在行中央静止悬停约 0.9 秒，整行变蓝高亮，松手即移入
- 展开有防误触保护：停留在行的**上/下边缘**对准插入线时**不会**触发展开；一次展开后光标不移动也不会连锁展开其他文件夹
- 根层级空白处松手 = 移到根层级末尾
- 拖拽时不会触发原生「移入文件夹」高亮或意外展开

## 命令

- `清除全部自定义排序`：恢复 Obsidian 默认排序
- `重新应用自定义排序`：显示异常时手动刷新

## 数据

顺序保存在插件自身的 `data.json`，结构为 `{ "orders": { "<父目录路径>": ["子项名", ...] } }`。
移动文件走 Obsidian 官方 renameFile（自动更新双链），重命名/删除时顺序自动同步。

## 卸载

设置 → 第三方插件 → 关闭并移除本插件即可，不影响任何笔记。

## 排序规则（v1.4）

**右键任意文件夹 → 「排序规则」**，可单独为该文件夹设置：

- 默认（跟随全局排序 / 拖拽自定义顺序）
- 名称 A→Z / Z→A
- 创建时间 旧→新 / 新→旧
- 修改时间 旧→新 / 新→旧

规则**优先于**拖拽顺序：设了规则的文件夹按规则排，想恢复拖拽自由排序选「默认」即可。

注意：Obsidian 原生的排序规则只作用于**文件**，子文件夹固定按名称排在文件前面。本插件做了增强：选「名称 Z→A」时**子文件夹也会倒序**（日期命名的文件夹从此最新在最上）；其余规则（时间类）对子文件夹仍按名称升序（文件夹没有时间属性）。
